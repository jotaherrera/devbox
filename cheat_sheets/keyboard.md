# ⚡ VS Code / Cursor Keyboard Cheat Sheet

## 🔍 Navigation
- **Go to line** → `Ctrl + G` / `Cmd + G`
- **Quick open file** → `Ctrl + P` / `Cmd + P`  
  - `:25` → jump to line 25  
  - `#function` → jump to function/class  
- **Symbols in file** → `Ctrl + Shift + O` / `Cmd + Shift + O`
- **Symbols in workspace** → `Ctrl + T` / `Cmd + T`
- **Go to definition** → `F12`
- **Peek definition** → `Alt + F12`
- **Find references** → `Shift + F12`
- **Jump between brackets** → `Ctrl + Shift + \`
- **Switch recent files** → `Ctrl + Tab` / `Ctrl + Shift + Tab`
- **Cursor history** → Back `Ctrl + -`, Forward `Ctrl + Shift + -`

---

## 🚀 Selection
- **Select word** → `Ctrl + D` / `Cmd + D`
- **Expand selection (semantic)** → `Shift + Alt + Right`
- **Shrink selection** → `Shift + Alt + Left`
- **Select line** → `Ctrl + L`
- **Select all** → `Ctrl + A`
- **Column/box selection** → `Shift + Alt + Drag` or `Ctrl + Alt + ↑ / ↓`

---

## ✂️ Deletion & editing
- **Delete word left** → `Ctrl + Backspace`
- **Delete word right** → `Ctrl + Delete`
- **Delete line** → `Ctrl + Shift + K`
- **Cut line** → `Ctrl + X` (no selection needed)
- **Duplicate line** → `Shift + Alt + ↓ / ↑`
- **Move line** → `Alt + ↑ / ↓`

---

## ⌨️ Multi-cursor
- **Next occurrence** → `Ctrl + D` / `Cmd + D`
- **Skip occurrence** → `Ctrl + K, Ctrl + D`
- **Add cursor manually** → `Alt + Click`
- **Vertical cursors** → `Ctrl + Alt + ↑ / ↓`

---

## 🛠️ Productivity
- **Command Palette** → `Ctrl + Shift + P` / `Cmd + Shift + P`
- **Split editor** → `Ctrl + \`
- **Focus editor group** → `Ctrl + 1 / 2 / 3`
- **Toggle terminal** → `Ctrl + \`` (`` ` `` key)
- **Search in project** → `Ctrl + Shift + F`

---

## 💡 Pro tips
- Combine quick open + jump:  
  `file:25#function`
- Use **VSCodeVim** for advanced, Vim-style motion (`w`, `b`, `{`, `}`).
